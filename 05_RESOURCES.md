# 📚 Placement Preparation Master Resources (PEP)

Curated list of top-tier websites, documentation, YouTube playlists, platforms, and books for placement preparation.

---

## 💻 01. C++ Programming Resources

### 📖 Documentation & Reading
- [cppreference.com](https://en.cppreference.com/w/) — Absolute authority on C++ standard library, syntax, and features.
- [LearnCpp.com](https://www.learncpp.com/) — Free, comprehensive step-by-step C++ tutorial series.
- [GeeksforGeeks C++ Programming](https://www.geeksforgeeks.org/c-plus-plus/) — Quick syntax reference and concept guides.

### 🎥 Recommended Playlists
- **striver / Take U Forward:** C++ Basics to Advanced STL Playlist.
- **Love Babbar:** Complete C++ & DSA Course.
- **Cherno:** C++ Deep-Dive Series (Pointers, Memory, Object Lifetime).

## 🧠 02. Data Structures & Algorithms (DSA)

### 🏋️ Practice Platforms
- [LeetCode](https://leetcode.com/) — Industry standard for coding interviews.
- [CodeStudio / Coding Ninjas](https://www.naukri.com/code360) — Excellent collection of company-wise interview questions.
- [GeeksforGeeks Practice](https://practice.geeksforgeeks.org/) — Top platform for campus placement problem sets.
- [CSES Problem Set](https://cses.fi/problemset/) — Pure algorithm practice.

### 🗺️ Sheets & Roadmaps
- **Striver A2Z DSA Sheet** (Take U Forward)
- **NeetCode 150** (Pattern-based DSA preparation)
- **Love Babbar 450 Sheet**
