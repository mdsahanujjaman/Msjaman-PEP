## 🧠 Phase 2: DSA Problem-Solving Curriculum (17 Topics)

1. **Introduction to DSA & Time/Space Complexity:** Big-O, Big-Omega, Big-Theta notation, space-time trade-offs.
2. **Arrays:** 1D, 2D arrays, prefix sums, sliding window, two-pointer techniques.
3. **Strings:** Pattern matching, string manipulation, KMP / Rabin-Karp basics.
4. **Recursion & Backtracking:** N-Queens, Subsets, Permutations, Sudoku Solver.
5. **Searching Algorithms:** Binary Search, Search in Rotated Sorted Array, Ternary Search.
6. **Sorting Algorithms:** Bubble, Selection, Insertion, Merge Sort, Quick Sort, Count Sort.
7. **Linked Lists:** Singly, Doubly, Circular, Fast/Slow Pointers, Reversal, Cycle Detection.
8. **Stacks:** Monotonic Stack, Next Greater Element, Expression Evaluation (Infix/Postfix).
9. **Queues:** Circular Queue, Priority Queue, Deque, Implementation using Stacks.
10. **Hashing:** Hash Tables, Collision Resolution, Frequency Counting, Subarray Sums.
11. **Trees & BST:** Binary Tree Traversals (In/Pre/Post/Level), LCA, BST Operations, AVL introduction.
12. **Heaps & Priority Queues:** Min-Heap, Max-Heap, Heapify, Kth Largest Element, Top K Frequent.
13. **Graphs:** BFS, DFS, Topological Sort, Dijkstra's Algorithm, Bellman-Ford, Kruskal's/Prim's, Disjoint Set.
14. **Greedy Algorithms:** Activity Selection, Fractional Knapsack, Job Sequencing, Huffman Coding.
15. **Dynamic Programming:** 1D DP, 2D Grid DP, Knapsack 0/1, Unbounded Knapsack, LCS, LIS, Matrix Chain Multiplication.
16. **Bit Manipulation:** Bitwise operators, XOR properties, Set/Clear bits, Single Number problem.
17. **Trie (Prefix Tree):** Insertion, Search, Prefix Matching, Auto-complete logic.
18. **Mock Coding Practice:** Timed problem-solving under real assessment constraints.

## 🗄️ Phase 3: Core CS & Software Engineering

### 1. Database Management Systems (DBMS) & SQL
- Relational Algebra, ER Models, 1NF/2NF/3NF/BCNF Normalization.
- Transactions, ACID Properties, Concurrency Control, Lock-based Protocols.
- SQL Mastery: DDL, DML, DCL, JOINS (Inner, Left, Right, Full), Group By, Having, Window Functions (`ROW_NUMBER()`, `RANK()`).

### 2. Operating Systems (OS)
- Process vs. Thread, Process Control Block (PCB), Context Switching.
- CPU Scheduling: FCFS, SJF, Round Robin, Priority Scheduling.
- Synchronization: Critical Section, Mutex, Semaphores, Producer-Consumer, Dining Philosophers.
- Deadlocks: Characterization, Prevention, Avoidance (Banker's Algorithm), Detection.
- Memory Management: Paging, Segmentation, Virtual Memory, Page Replacement (LRU, FIFO, Optimal).

### 3. Computer Networks (CN)
- OSI 7-Layer Model & TCP/IP 4-Layer Suite.
- Network Protocols: HTTP, HTTPS, TCP, UDP, IP, DNS, DHCP, FTP.
- TCP 3-Way Handshake, Flow Control (Sliding Window), Congestion Control.
- IP Addressing: IPv4 vs. IPv6, CIDR, Subnetting, MAC Address vs. IP Address.

### 4. Software Engineering & Tools
- Version Control: Git branching, merging, rebasing, pull requests, resolving conflicts.
- REST API Architecture: HTTP Methods (GET, POST, PUT, DELETE), Status Codes, JSON payloads.
- Clean Code Principles: SOLID principles, DRY, KISS, meaningful naming, refactoring.
